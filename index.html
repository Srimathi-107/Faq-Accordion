01 How does React's reconciliation algorithm optimize DOM updates?

React's reconciliation algorithm compares the previous Virtual DOM with the updated Virtual DOM using a process called diffing. It identifies the necessary changes and updates only the affected parts of the real DOM, improving rendering efficiency.

02 How does the JavaScript Event Loop handle microtasks and macrotasks?

The Event Loop manages asynchronous JavaScript execution. After the call stack becomes empty, JavaScript processes microtasks such as Promise callbacks before moving to the next macrotask, such as setTimeout callbacks.

03 What is the difference between JWT access tokens and refresh tokens?

Access tokens are short-lived credentials used to access protected resources. Refresh tokens are longer-lived credentials used to obtain new access tokens without requiring the user to log in again. Refresh tokens must be stored and validated securely.
